## 背景（30 秒版）

- **靶点**：`mfsT1`（*Mycolicibacterium neoaurum*，`WP_030133796.1`，428 aa，**MFS 二级主动转运体**）。
  它只在**表型**上被当作 EGT 外排候选（过表达把胞外占比 **18.7% → 44.9%**，**胞内仍留 55.1%**），**无实验结构、无结合/转运实验、原文自称 *putative***。
- **档 1–3 已完成**：
  - AF3 apo 模型（**pTM 0.82**，TM 区 pLDDT ≥82，构象偏外向开放）
  - 口袋 = **6 个芳香残基从 6 条不同 TM 汇聚成笼**（F350/Y14/Y53/H219/**F111**/F326）+ **R21**（TM1）+ **T227**（TM7）
  - Chai-1 复合物：EGT **三段式位姿、5/5 模型一致** —— 三甲铵→芳香笼（F111 最近 4.1–4.6 Å）｜羧基→**R21 盐桥**（2.7–3.3 Å）｜硫酮 S→**T227 CH···S**（3.2–3.4 Å）
  - hercynine 对照：**共享两段姿势一致，差异只在硫端**（rank_0：EGT 的 S 距 T227 **3.34 Å**；hercynine 的 C2–H **9.21 Å**）
  - 折叠互验：AF3 ↔ Chai-1 跨膜核心 Cα RMSD **0.64 Å**
- **本档要做的事（一句话）**：把这个"**已存在但未优化的识别化学雏形**"，变成**一组有排序、可湿实验检验的变体短名单**（10 条 + WT 分位）。

## ⛔ 三条纪律（贯穿全档）

1. **全部产出为计算级假设**（🖥/⚠️）。**禁止**出现"结合""亲和力""ΔΔG""识别机制已获得"等无实验支撑的表述。
2. **选择性偏置分 Δscore 是设计偏置量，不是亲和力差** —— 只用于在序列空间里排序。
3. **每档结束先落盘交付物与该档结果说明**，再决定是否继续下一档（避免"全做完才发现某步白做"）。
