## 2. 但请注意：这个 GO 带四个"新信息修正"（档 1 的实际增量）

### 2.1 叙事修正：从"NNP 样"改为"**身份不明的 MFS，且口袋不是 NarK 式**"
档 1 把"mfsT1 像 NarK"的认识**降级**了：profile 级命中仍在，但 NS 基序缺失 + Arg 对缺失 + 与 SLC22A4 等距（16–20% identity）→ **NarK 只能借折叠和口袋位置，不能借底物化学**。这**强化**（而非削弱）立项逻辑：天然 mfsT1 的底物谱连"阴离子"都不能假定，44.9% 胞外占比的"天花板"有了序列层解释。（⚠️ 序列层假设，待档 2 结构确认）

### 2.2 ⭐ 新线索：PANTHER 命中 **PTHR43124 = 嘌呤外排泵 PbuE**（E=1.1e-13）
杂环底物 + 外排方向——比 NarK（无机阴离子摄取/反转运）**更像 EGT 外排的物理类比对象**。
→ **档 2 新增前置小任务**：查 PbuE 有无实验结构 / AFDB 模型；若有，把"NarK 单模板比对"升级为"NarK + PbuE 双参照"。（⚠️ 弱命中，仅作线索）

### 2.3 Q6 的"不共定位"→ 机制最小实验的优先级上调
mfsT1 与 egt 通路**无任何基因组学关联**（整个 contig 无 egt 基因；邻域是 PKS/脂质代谢区）。"它是 EGT 转运体"**只剩表型一条线**（且 Table S3 显示另一个候选 NGR_a01730 转录响应更强但未报道表型）。
→ **建议（移交方向层决策）**：在投设计之前，先跑 §26.9 已列的"机制最小实验"（① mfsT1 是否直接结合/转运 EGT ② 方向性与耦合），或至少把它与设计**并行**。这不动档 2/3 的计算路线，只动湿实验排序。
→ 附带假设（⚠️ 仅记录）：mfsT1 上游的 **MerR 家族调控因子与其头对头**（~230 bp 间隔）——是否调控 mfsT1、是否响应氧化应激，是可检验的小实验。

### 2.4 备选/对照靶点：**gene3725（NGR_a01730，y4rN 样 MFS）**
Table S3 第一名（FC 4.74 > mfsT1 的 3.45），Ding 2024 做了过表达但未报道（⚠️ 推断为阴性或较弱）。若 mfsT1 路线在"底物验证"处受阻，它是现成的第二候选。
