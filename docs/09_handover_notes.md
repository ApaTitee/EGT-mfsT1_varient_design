## 3. 通盘考虑（初步结论与叙事修正）

### 3.1 ⭐ 叙事修正（档 1 预期 vs 档 2/3 实际）
档 1 序列层预期"口袋需要从零安装识别化学"；结构层显示：**天然口袋已具备三段识别化学的几何雏形**（笼 / R21 / T227 都在，但都未到 EgtUC 的晶体级优化程度）。
→ 建议叙事改为：**"mfsT1 能运 EGT 但不专职（44.9% 上限、putative）有其结构基础：识别化学雏形已存在但不优化；设计任务 = 把每个接触优化到晶体级几何 + 拉开对 hercynine 的选择性差距"**。
→ 这比"从零安装"**可行性更高、且与设计动作（位点级优化）直接对应**；同时保留"识别化学从未被工程化"的原创性主张。

### 3.2 对老师那条问题的完整回答（可上页口径）
"EgtUc 是 transporter 还是 channel" → **两种读法答案都是"不是 channel"**：我们的靶点 mfsT1 = MFS 二级主动转运体（transporter）；图上若指 EgtUC，它是 ABC 摄取转运体的可溶 SBD，也不是膜蛋白/通道。**MFS 无通道成员**；transporter 的功能载体是能量景观（多态交替开放）而非单一开放态——这决定了设计要管"结合+循环"两件事（§26.9 难度差表）。
