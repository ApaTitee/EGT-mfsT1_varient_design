> **问题**：mfsT1 是否与 `egtA/B/C/D/E`、`hisG`、SAM 循环基因共定位/共调控？（= "它是 EGT 通路相关转运体"的唯一潜独立证据）

---

## 1. ⭐ 结论：**不共定位（No）**

> **mfsT1 不在 egt 基因簇附近，也不与任何 EGT 通路基因共定位。**
> - 其上下游 ±20 kb 内**无** `egtA/B/C/D/E`、`hisG`、SAM 循环基因；
> - **整个 contig_5（`NZ_JMDW01000005.1`）上没有任何 egt 基因**（全 contig 特征表 0 命中）→ egt 簇在该基因组的**其他 contig** 上。

按 PLAN §3 Step 5 的分寸约定：**没有共定位 ≠ 否定方向**。它意味着"独立证据缺失"，立论仍只有 Ding 2024 的两条（转录差异 + 过表达表型），在放行判据中相应降权（见 `06_stage1_conclusion_and_gate.md`）。

## 2. mfsT1 的实际邻域（±20 kb，40 kb 窗口共 35 个 CDS）

```
... → type I polyketide synthase（309323-318553，9.2 kb 巨酶）
      MerR 家族转录调控因子（319106-319646，负链）─── 约 230 bp 间隔 ─── ⭐ mfsT1（319880-321166，正链）
      LtrA（low temperature requirement protein A，321156-322364，负链，尾对尾）
      IspD/TarI 胞苷酰转移酶 ×2 → FadD3 酰基-CoA 连接酶 → amidohydrolase → AMP-binding
      → enoyl-CoA hydratase → TetR 调控因子 → CYP450 → ... → MCE 家族蛋白 ×3（脂质转运）
```

**区域性质**：这是一个**次级代谢 / 脂质代谢富集区**（PKS 巨酶、异戊二烯合成、脂肪酸代谢、MCE 脂质转运蛋白），**不是** EGT 合成区。
